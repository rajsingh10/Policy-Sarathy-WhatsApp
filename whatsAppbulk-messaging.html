WhatsApp Bulk Messaging Panel

WhatsApp Bulk Messaging Platform.

Complete documentation for the WhatsApp Bulk Messaging system serving business administrators and support teams. The platform manages contact audiences, automated WhatsApp campaigns, official WABA template syncing, live customer chat, and subscription billing.

View Platform Overview View Modules

Platform Overview

The web platform is the primary interface for businesses utilizing the WhatsApp Cloud API. It provides a comprehensive suite of tools to automate and track messaging at scale.

Dashboard

Real-time analytics for campaign deliveries, read receipts, and WABA connection health.

Campaigns

Schedule and track bulk message blasts using approved WhatsApp templates.

Contacts & Groups

Import CSV datasets and segment customers into groups for targeted marketing.

Live Chat Hub

Manage incoming customer replies and provide support in a unified inbox.

Templates

Sync, create, and submit Marketing, Utility, and Auth templates to Meta.

Credits & Wallet

Manage messaging quota, recharge balance, and view subscription plans.

Campaign Workflow

  1. Template Sync. Navigate to Templates and sync your approved WABA templates from Meta.
  2. Import Audience. Go to Contacts and use the CSV Importer to upload your customer list. Format columns properly for dynamic variables.
  3. Create Segment. Group your contacts (e.g., "Diwali Offer Audience") in the Groups module.
  4. Launch Campaign. Open the Bulk Sender (/bulk-send), select your target Group, pick an approved Template, and map any dynamic variables.
  5. Monitor Delivery. Navigate to Reports to view real-time statistics (Sent, Delivered, Read, Failed) processed by backend webhooks.

Dashboard & Reports Deep Dive

The analytics engine gives business owners full visibility into their WhatsApp ROI.

Dashboard (Dashboard.jsx)

The dashboard fetches aggregated data via the dashboardSlice. It displays a summary of total credits spent, messages delivered, and an interactive chart showing sending trends over the last 30 days. It also highlights the current WhatsApp Business Account (WABA) health rating (Green/Yellow/Red).

Reports (Reports.tsx)

Provides granular row-by-row tracking. Users can filter by date range or campaign to see exactly which phone numbers received the message, which failed (e.g., invalid number), and who read it. You can export these reports back to CSV.

Contacts & Groups Deep Dive

Managing large lists effectively is critical for bulk messaging.

  • Contacts Directory (Contacts.jsx): A paginated data table showing all numbers. Supports inline editing and deletion.
  • CSV Import Modal: Automatically maps standard CSV headers (Name, Phone, Email, Custom 1, Custom 2) to the database. Bad numbers are auto-filtered out.
  • Group Segmentation (Groups.tsx): Create specific lists like "VIP Customers" or "Cart Abandoners". In GroupDetails.tsx, you can add or remove individuals from the group dynamically before a blast.

WABA Templates Deep Dive

Meta enforces strict rules on outbound messaging. You must use pre-approved templates.

Feature Component Description
Template Syncing Templates.jsx Pulls the latest approved templates from Meta via the backend API. Displays category (Marketing, Utility) and language.
Creation Form CreateTemplate.tsx A wizard to build templates. Supports header types (Text, Image, Document), body text with variables ({{1}}), footer text, and interactive buttons (Call to Action or Quick Reply).
Template Preview TemplateView.tsx Renders a live mockup of how the template will look on a customer's phone before you send it.

Bulk Sender & Campaigns Deep Dive

The /bulk-send route is the core engine of the platform, designed to prevent mistakes during large broadcasts.

  1. Target Selection: Choose a pre-defined Group. The system calculates the estimated credit cost based on audience size.
  2. Template Picker: Select an approved template. Unapproved or rejected templates are disabled.
  3. Variable Mapping (Crucial): Map dynamic placeholders (e.g., {{1}} = Name, {{2}} = Discount Code). The UI generates a preview based on the first contact in the group.
  4. Media Upload: If the template has a media header, upload the specific Image or PDF via the MediaModule.jsx integration.
  5. Scheduling: Dispatch the campaign immediately, or pick a future date and time. Handled by Laravel queues on the backend.

Live Chat Interface Deep Dive

Provides customer support directly over WhatsApp via Chat.jsx.

24-Hour Rule: You can only send free-form text messages to customers who have messaged you within the last 24 hours. Otherwise, the UI restricts you to sending approved Templates.
  • Inbox View: Lists all active conversations on the left pane, sorted by most recent.
  • Thread View (ConversationDetails.jsx): Real-time message history. Supports rendering incoming images, audio notes, and location pins.
  • Message Inspector (MessageDetails.jsx): Click on any sent message to see exact timestamps for Sent, Delivered, and Read statuses.

Automation & Settings Deep Dive

Configure the system behavior and WABA connections.

  • Global Settings (Settings.tsx): Configure timezones, default notification preferences, and team member roles.
  • WABA Status (WABAStatus.tsx): Monitor webhook connection, phone number quality, and messaging limits (e.g., Tier 1 = 1k msgs/day, Tier 2 = 10k msgs/day).
  • Automation (Automation.tsx): Setup auto-replies (e.g., "Out of Office" messages) or keyword-based routing for incoming messages.

Redux Slices Reference

The application uses Redux Toolkit (stored in src/features) to manage API calls and state centrally.

Slice Directory Primary Actions & Purpose
features/auth/ login, logout, getProfile. Stores JWT token securely and handles session state.
features/contacts/ fetchContacts, importCSV, deleteContact. Manages pagination and search filters for the audience directory.
features/groups/ fetchGroups, addContactsToGroup. Handles segmentation logic for broadcasts.
features/templates/ syncTemplates, createTemplate. Interacts with the backend to proxy requests to Meta's WhatsApp API.
features/bulkSend/ initiateBulkSend, scheduleCampaign. Constructs the complex JSON payload mapping variables to contacts for the queuing system.
features/conversations/ fetchChats, sendMessage. Uses polling or WebSockets to maintain real-time chat state.
features/dashboard/ fetchAnalytics. Retrieves aggregated metrics for Chart.js rendering.
features/credits/ fetchWallet, initiatePayment. Manages financial transactions and gating.

Local Setup

The frontend uses Vite, React, and TailwindCSS. Make sure you have Node 18+ installed.

Install Web Panel 
cd whatsAppbulk-messaging-demo
npm install
npm run dev
Environment Variables: Ensure you copy .env.example to .env and set VITE_API_BASE_URL to point to your local Laravel backend API (e.g., http://localhost:8000/api).

Common Issues

Issue Likely Cause Fix
Stuck on "Choose a plan to continue" No active subscription plan. The SubscriptionGuard component blocks access to core routes. Complete a plan purchase or assign one via the backend database.
Messages stuck in "Sent" status Webhooks not configured. Ensure the Laravel backend webhook URL is registered in the Meta Developer Dashboard and the server is publicly accessible (use ngrok locally).
Cannot send Free-form Chat Outside 24-hour window. WhatsApp policy restricts free-form replies if the user hasn't messaged you in 24 hours. You must send an approved template instead.
Template variables not rendering Mismatched mapping in bulkSendSlice. Ensure the number of variables mapped in the UI exactly matches the placeholders defined in the Meta template.
